# Machine-Learning-Employee-Retention
In this project, logistic regression is used to model the relationship between employee attributes and the likelihood of leaving the company. The model is trained on historical employee data, using key variables such as satisfaction level, average monthly hours, number of projects, and promotion in the last five years as predictors. Logistic regression estimates the probability of attrition for each employee, allowing us to identify which factors have the strongest impact on retention. By analyzing the model coefficients and predicted probabilities, we gain actionable insights into patterns of employee turnover and can make data-driven recommendations to improve retention strategies.
